# 霓虹疾跑 / Neon Dash

赛博朋克紫色像素风的**横屏双轨跑酷**。灵感取自《喵斯快跑》的上/下双轨操作，改造为无限跑酷：仅用**上下键**切换轨道，躲开红色障碍、吃金色光点冲高分。原生 HTML5 Canvas + ES Modules 自研引擎，零构建、静态可部署。

> 秋招个人旗舰作品（P0）。"系统即内容"：障碍程序生成，内容无限，主打手感与技术美术。

## 玩法

- **↑ / W**：切到上轨　**↓ / S**：切到下轨
- 障碍（红）与光点（金）从右侧涌来，与你**同轨**才会碰到
- 撞障碍即结束；吃光点加分；速度随时间越来越快
- **Enter**：结算后重新开始（自动记录本地最高分）

## 本地运行

```bash
python -m http.server 5500   # 或 npx serve .
# 浏览器打开 http://localhost:5500
```

## 目录结构

```

   ├─ main.js

   ├─ data/config.js 全部手感/难度参数集中可调
   ├─ systems/
   │  ├─ Player.js       双轨切换 + 切轨插值 + 拖尾 + 挤压拉伸

   │  ├─ Particles.js    粒子反馈（juice）
   │  └─ Background.js    多层视差霓虹城市 + 滚动地面
   └─ scenes/
      ├─ TitleScene.js
      └─ RunScene.js     碰撞 / 计分 / 屏震顿帧 / 结算
```

## 技术看点（面试叙事）

- 自研游戏循环（dt 上限、场景栈）与整数放大像素渲染管线
- **程序化内容生成**：障碍/光点随机布轨 + 难度随时间爬升（系统即内容）
- **手感/juice 全家桶**：切轨挤压拉伸、拖尾、粒子爆发、屏震、碰撞顿帧
- 多层视差背景营造速度感
- 参数集中在 `config.js`，可快速调优（TA/客户端最看重的"手感调参"能力）
